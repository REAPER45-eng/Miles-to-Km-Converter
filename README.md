# Miles to Kilometers Converter

A simple desktop application developed using Python and Tkinter. The application converts distances from miles to kilometers through a graphical user interface.

## Features

- Enter a distance in miles.
- Convert miles to kilometers.
- Display the converted result.
- Results rounded to two decimal places.

## Built With

- Python 3
- Tkinter

## Conversion Formula

1 mile = 1.60934 kilometers

```python
kilometers = miles * 1.60934
```
